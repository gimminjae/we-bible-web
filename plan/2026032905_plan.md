# 교회 상세 페이지 탭 UI 단순화

## 1. 프롬프트 기록
- 교회 상세 페이지의 탭 메뉴에서는 아이콘만 보이도록 수정한다.
- 탭 메뉴 하단에는 현재 메뉴명을 제목처럼 노출한다.

## 2. 분석한 내용
- 현재 교회 상세 페이지 탭은 아이콘과 텍스트를 같은 줄에 보여주고 있어 모바일에서 간격이 좁고 시선이 분산된다.
- 사용자가 원하는 구조는 상단 탭 바에서는 아이콘 중심으로만 탐색하고, 실제 메뉴명은 탭 아래의 섹션 제목처럼 분리해서 읽게 만드는 형태다.
- 변경 범위는 `src/app/churches/[id]/page.tsx` 내부 탭 UI와 활성 탭 제목 표시 영역으로 제한된다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- 교회 상세 페이지 탭 버튼에서 텍스트를 제거하고 접근성을 위해 `aria-label`만 유지한다.
- 현재 활성 탭의 메뉴명을 탭 바 아래 별도 제목으로 노출한다.
- 문서 `추가 반영 사항`을 갱신하고 `npm run lint`, `npm run build`로 검증한다.
