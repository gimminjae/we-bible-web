# Supabase schema.sql 달러쿼트 오류 수정

## 1. 프롬프트 기록
- `supabase/schema.sql` 실행 시 `unterminated dollar-quoted string` 에러가 발생한다.
- `$$` 구문 때문에 SQL Editor에서 함수 정의가 정상 종료되지 않는 문제를 수정한다.

## 2. 분석한 내용
- 새로 추가한 교회 공용 기도 관련 함수들은 로컬 파일상 `$$` 짝은 맞지만, SQL Editor에서 일부 블록만 실행하거나 편집기 파싱이 흔들릴 때 `$$` 기반 함수 정의가 오류를 내는 경우가 있다.
- 특히 여러 함수가 연속 배치된 구간에서는 일반 `$$` 대신 의미 있는 이름의 달러 태그를 쓰면 실행 안정성이 더 높다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- 공용 기도 관련 함수 정의를 중심으로 `$$`를 명시적인 이름 태그 달러쿼트로 변경한다.
- 수정 후 해당 구간의 열림/닫힘 태그가 정확히 맞는지 다시 확인한다.
- 사용자가 Supabase SQL Editor에서 다시 실행할 수 있도록 적용 지점을 정리한다.
