# 교회 기능에 공용 기도 목록 결합

## 1. 프롬프트 기록
- 기도 목록 기능을 교회 기능에 결합한다.
- 기도 데이터에 교회, 팀 아이디 필드 추가 가능성을 참고한다.
- 교회 내에서 함께 기도하고자 하는 내용을 교회와 팀별로 기록할 수 있도록 구현한다.

## 2. 분석한 내용
- 현재 기도 기능은 `prayers`, `prayer_contents`를 기반으로 한 개인 소유 데이터이며 `user_id` 기준 RLS만 적용되어 있다.
- 교회 기능은 `churches`, `teams`, `church_memberships`와 `plans/plan_progresses`를 이용해 공용 데이터와 권한을 분리해서 다루고 있다.
- 교회 공용 기도는 개인 기도와 사용 목적과 접근 권한이 다르므로 기존 개인 기도 테이블에 직접 섞기보다 교회 범위 전용 테이블을 별도로 두는 편이 안전하다.
- 교회 상세 페이지는 현재 `회원`, `성경읽기 계획`, `팀` 탭으로 구성되어 있으므로 `기도` 탭을 추가하는 방식이 가장 자연스럽다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- `supabase/schema.sql`에 교회/팀 공용 기도와 기도 내용 이력용 테이블, 필요한 인덱스와 RLS 정책을 추가한다.
- `src/lib/church.ts`와 `src/hooks/use-churches.ts`에 교회 공용 기도 조회/생성/수정/삭제 함수를 추가한다.
- `src/app/churches/[id]/page.tsx`에 `기도` 탭을 추가하고 교회 전체 기도 및 팀 기도 목록, 생성/수정 UI를 구현한다.
- 관련 다국어 문구와 계획 문서의 `추가 반영 사항`을 갱신하고 `npm run lint`, `npm run build`로 검증한다.
