# 교회 공용 계획 상세 페이지 에러 수정

## 1. 프롬프트 기록
- `https://we-bible-web.netlify.app/churches/1/plans/1` 페이지에서 클라이언트 에러가 발생하므로 원인을 확인하고 수정한다.

## 2. 분석한 내용
- 교회 공용 계획 상세 페이지는 `useHeader`로 헤더 액션을 주입하고 있다.
- 페이지에서 `useChurchActions()`가 반환한 함수와 `sharedPlanDetail` 전체 객체를 헤더 effect 의존성으로 직접 참조하고 있다.
- 헤더 컨텍스트 갱신이 페이지 재렌더를 유발할 때, 의존성이 매번 새로 바뀌면 반복적으로 `setHeader`가 호출되어 렌더 루프가 발생할 가능성이 높다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- 교회 액션 훅 반환값의 참조 안정성을 점검하고 필요한 경우 메모이제이션을 적용한다.
- 공용 계획 상세 페이지의 헤더 의존성을 스칼라 값과 메모이즈된 핸들러로 축소한다.
- `lint`와 `build`로 회귀 여부를 확인한다.
