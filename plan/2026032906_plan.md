# toast 기능을 react-toastify 기반으로 재구현

## 1. 프롬프트 기록
- 프로젝트 내의 toast 기능을 `react-toastify` 오픈소스 라이브러리를 사용해서 재구현한다.
- 각 파일에서 `react-toastify`를 직접 사용하지 않고 `useToast` 커스텀 훅으로 감싸서 사용하도록 구현한다.

## 2. 분석한 내용
- 현재 토스트 시스템은 `zustand` 기반 `toast-store`와 자체 `ToastViewport` 컴포넌트로 구성되어 있다.
- 실제 화면 호출부는 대부분 `useToast().showToast(message)` 형태로 통일되어 있어, 이 API를 유지하면 교체 범위를 내부 구현으로 제한할 수 있다.
- `react-toastify` 공식 문서는 앱 루트에 `ToastContainer`를 한 번 렌더하고 `toast(...)`로 호출하는 패턴을 권장하므로, 현재 `Providers`의 토스트 마운트 지점을 그대로 활용할 수 있다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- `react-toastify` 의존성을 추가하고, 기존 자체 store 기반 토스트 구현을 제거한다.
- `useToast` 훅은 앱에서 계속 `showToast`를 제공하되 내부에서 `react-toastify`를 호출하도록 변경한다.
- 앱 루트의 토스트 렌더러를 `ToastContainer` 기반으로 교체하고, 프로젝트 스타일에 맞게 기본 옵션과 스타일을 조정한다.
- 문서 `추가 반영 사항`을 갱신하고 `npm run lint`, `npm run build`로 검증한다.
