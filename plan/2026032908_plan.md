# react-toastify 기본 스타일에 가깝게 재정리

## 1. 프롬프트 기록
- 현재 toast UI가 사용자가 알고 있는 `react-toastify` 기본 모양과 너무 다르게 보인다.
- toast가 더 표준적인 `react-toastify` 스타일에 가깝게 나오도록 수정한다.

## 2. 분석한 내용
- 현재는 `react-toastify` 기본 CSS 위에 `.Toastify__toast`, `.Toastify__toast-body` 등의 구조 클래스에 커스텀 스타일을 강하게 덮어쓰고 있다.
- 이 방식은 기본 레이아웃, 패딩, 배경, 본문 흐름까지 바뀌어서 사용자가 알고 있는 기본 `react-toastify`와 시각적으로 크게 달라진다.
- 이번 수정은 커스텀 Toastify CSS를 대부분 제거하고 라이브러리 기본 스타일을 살리는 방향이 가장 안전하다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- `src/app/globals.css`의 Toastify 전용 커스텀 스타일을 최소화하거나 제거한다.
- `ToastContainer` 옵션도 과도한 커스텀 없이 기본 동작에 더 가까운 방향으로 정리한다.
- 문서 `추가 반영 사항`을 갱신하고 `npm run lint`, `npm run build`로 검증한다.
