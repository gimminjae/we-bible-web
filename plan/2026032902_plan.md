# 설정 페이지 닉네임 변경 기능 추가

## 1. 프롬프트 기록
- 설정 페이지에서 자신의 닉네임을 표시하고 변경할 수 있도록 구현한다.
- 닉네임 변경 버튼을 누르면 변경 모달이 열리도록 한다.
- 저장 버튼을 누르면 닉네임이 실제로 변경되도록 한다.

## 2. 분석한 내용
- 설정 페이지는 현재 계정 상태와 로그인/로그아웃 UI는 있지만 닉네임 표시 및 변경 기능은 없다.
- 교회 기능은 `user_profiles.display_name`을 기준으로 표시 이름을 사용하므로 닉네임 변경은 이 테이블을 우선 갱신해야 한다.
- 현재 프로젝트는 바텀시트 UI를 공용 모달 패턴으로 사용하고 있으므로 같은 패턴을 재사용하는 것이 자연스럽다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- 현재 사용자 닉네임을 조회/저장하는 함수와 훅 또는 페이지 로직을 추가한다.
- 설정 페이지에 현재 닉네임 표시와 변경 버튼, 입력용 바텀시트를 구현한다.
- 저장 후 UI와 관련 데이터가 즉시 갱신되는지 확인하고 lint/build로 검증한다.
