# react-toastify 토스트 텍스트 미노출 수정

## 1. 프롬프트 기록
- `react-toastify`로 교체한 toast에서 텍스트가 노출되지 않는 문제를 수정한다.

## 2. 분석한 내용
- 현재 `ToastContainer`에 `toastClassName={() => "toastify-toast"}`를 전달하고 있어, 기본 `Toastify__toast` 계열 클래스 조합이 함수 반환값으로 대체되고 있다.
- `react-toastify` v11은 `toastClassName` 함수에 `defaultClassName`을 넘겨주지만, 현재 구현은 이를 무시하고 있어 기본 레이아웃/텍스트 스타일이 깨질 가능성이 높다.
- 가장 안전한 방식은 `toastClassName` 커스텀 함수를 제거하고, 기본 `.Toastify__toast`, `.Toastify__toast-body` 클래스를 프로젝트 스타일로 직접 덮어쓰는 것이다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- `ToastContainer`의 커스텀 `toastClassName` 설정을 제거한다.
- 전역 CSS를 기본 `Toastify__toast` 계열 클래스 기준으로 재정리해 텍스트와 배경이 확실히 보이도록 수정한다.
- 문서 `추가 반영 사항`을 갱신하고 `npm run lint`, `npm run build`로 검증한다.
