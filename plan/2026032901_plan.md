# 메뉴/버튼 아이콘 공통화 및 react-icons 전환

## 1. 프롬프트 기록
- 모든 메뉴와 버튼에 적절한 아이콘을 추가한다.
- 아이콘은 react-icons를 사용한다.
- 아이콘은 components/icons 폴더에서 컴포넌트화해서 사용한다.

## 2. 분석한 내용
- 현재 앱 전반은 lucide-react 아이콘을 직접 화면 파일에서 import해서 사용 중이다.
- 메뉴성 UI는 하단 탭, 마이페이지 메뉴 카드, 설정/상세 헤더 액션, 주요 생성/수정/삭제 버튼으로 분산되어 있다.
- 공통 아이콘 레이어가 없어 화면마다 직접 아이콘 라이브러리에 의존하고 있다.

## 3. 해당 프롬프트를 완수하기 위한 계획
- react-icons 의존성을 추가하고 components/icons 폴더에 공용 아이콘 컴포넌트 모음을 만든다.
- 기존 lucide-react 사용 지점을 공용 아이콘 컴포넌트로 치환하고, 메뉴/주요 액션 버튼에 빠진 아이콘도 보강한다.
- lint와 build로 전체 화면이 깨지지 않는지 확인한다.
